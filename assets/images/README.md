# Folder Gambar dan Logo DECHO

Simpan seluruh aset visual website di folder `assets/images/`.

## Struktur yang disarankan

- `logo-decho.png` — logo utama
- `logo-decho.webp` — logo versi ringan untuk website
- `moveable-bridge-bawean.webp` — proyek moveable bridge Pelabuhan Bawean
- `catwalk-control-room-bawean.webp` — proyek catwalk dan control room
- `frontal-frame-paciran-probolinggo.webp` — proyek frontal frame
- `warehouse-probolinggo-paciran.webp` — proyek warehouse
- `moveable-bridge-jangkar.webp` — proyek moveable bridge Pelabuhan Jangkar
- `residential-house-rungkut.webp` — proyek rumah tinggal Rungkut City

Gunakan nama file huruf kecil, tanpa spasi, dan pisahkan kata dengan tanda hubung (`-`). Format WebP disarankan untuk foto website; PNG tetap cocok untuk logo transparan.

Contoh pemanggilan dari halaman HTML di root repository:

```html
<img src="assets/images/logo-decho.png" alt="Logo DECHO">
<img src="assets/images/warehouse-probolinggo-paciran.webp" alt="Proyek warehouse DECHO">
```
