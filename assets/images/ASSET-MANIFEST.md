## Aset yang perlu ditempatkan di folder ini

### Logo
- `logo-decho.png` — logo asli dengan transparansi
- `logo-decho.webp` — versi ringan untuk tampilan website

### Foto yang dikirim terpisah
- `residential-house-rungkut.webp` — konstruksi dan rumah selesai
- `warehouse-construction-01.webp` — struktur dan proses pembangunan gudang
- `warehouse-construction-02.webp` — bangunan gudang dan tampilan udara
- `moveable-bridge-bawean.webp` — fabrikasi dan struktur moveable bridge
- `moveable-bridge-port.webp` — moveable bridge di area pelabuhan

## Catatan
File README ini mendokumentasikan penamaan aset yang dituju, bukan bukti bahwa berkas gambar sudah diunggah. Letakkan file gambar asli/WebP di folder ini sebelum menggunakannya pada halaman HTML. Jangan mengganti logo asli dengan gambar hasil tangkapan layar jika file logo transparan tersedia.
